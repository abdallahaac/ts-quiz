Add a question — one row at a time

  1. Use the empty row below, or click inside a question and choose Table → Row → Insert row after (sometimes labelled Insert row below).
  2. Fill the four cells. In Answers, press Enter between choices and type [CORRECT] before exactly one answer.
  3. Click Save and Close to update the carousel. Repeat row insertion whenever you need another question; there is no fixed question count.

Field tips: Use Heading 2 for the question. Instructions are optional. Include at least two answers and feedback. Entirely empty rows are ignored; finish or delete partly completed rows.

Remove a question: Click in its row and choose Table → Row → Delete row. Keep the four column headings and at least one complete question. Do not merge cells or add columns. Use fullscreen for more room.

Which action makes a link’s purpose easier to understand?

Choose one answer, then select Check.

Use “click here” for every link.

[CORRECT] Use descriptive link text that explains the destination.

Remove the link’s visible underline.

Use colour as the only indication that text is a link.

Descriptive link text helps readers understand where a link leads. For example, Read the accessibility guide communicates more than click here.

Which of these is an example of semantic HTML?

Choose one answer, then select Check.

Use a generic container for every element regardless of its meaning.

[CORRECT] Use a heading element to identify a section heading.

Use CSS classes instead of headings.

Use bold text alone to communicate document structure.

Semantic elements describe the role of content. A heading element conveys document structure to browsers and assistive technologies.
