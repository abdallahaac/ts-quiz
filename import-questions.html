Import questions from Word

Prepare questions in Microsoft Word, then use this page to generate an updated Brightspace quiz. The Word file stays in your browser; it is not sent to a server.

Word table format: Four columns named Question, Instructions, Answers, and Feedback. Each question is one row. Put each answer in a separate paragraph in the Answers cell and prefix exactly one with [CORRECT].

1. Select your Word document

Choose a Word document to begin.

2. Source quiz HTML (optional)

Normally, the importer reads index.html from its own folder. If this is blocked, or you want to preserve a specific edited version, select the current quiz HTML file from Brightspace Manage Files.

Always use the latest course copy to avoid overwriting someone else's edits.
